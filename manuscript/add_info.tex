\section*{Additional Information}
\subsection*{Data Availability}
All inputs are published. Posterior draws of $V_A$ are from the data archive of Bonnet et al.~\cite{bonnet2022}; genome assemblies and annotations are from NCBI; mutation rates and nucleotide diversity are from Wang and Obbard~\cite{wangobbard2023}, Lewin and Eyre-Walker~\cite{lewin2026} and the sources listed in Methods; census sizes are from Buffalo~\cite{buffalo2021}; and DFE parameters are from Lin et al.~\cite{lin2026}. One data layer (\texttt{scripts/R/00\_prepare\_data.R}) joins these sources through a single population crosswalk and writes the tables that every analysis reads. Analyses were run in R 4.6.0, with posterior modes and HPD intervals from MCMCglmm and coda, and data handling and figures with dplyr, tidyr, readr, readxl and ggplot2. All code for the simulations, analysis and figure production, and the processed input tables, are available in the GitHub repository \textbf{TBD}.
